## 质量门禁与执行基准

1. **零外部网络穿透（CI 环境）**：单元与集成测试在无外网依赖下全量自动化执行完成（Mock LLM / Mock Web Search）；
2. **状态与进程隔离测试**：沙箱测试在执行后验证 PGID 进程树彻底消亡（`kill -9` 逃逸零容忍）；
3. **断电续跑测试**：端到端测试覆盖中间节点强制崩溃后，依托 SQLite Checkpoint 状态恢复与幂等重跑。
